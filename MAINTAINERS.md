# Project Maintainers

To reach the maintainers regarding governance or general questions, please open a discussion on [GitHub Discussions](https://github.com/cordanaLLM/imago/discussions). For confidential security matters, use [GitHub Security Advisories](https://github.com/cordanaLLM/imago/security/advisories/new).

Maintainers execute operational responsibilities following the deterministic [Maintenance Cadences](docs/operations/maintenance-cadence.md) (Weekly, Monthly, Quarterly, and Annual) and enforce PR hard gates via `imago`.
